# GestureChallenge — paquete de trabajo v2.0

Este paquete conserva la aplicación base y las funcionalidades v2.0 agregadas previamente. Consulte [PHASE-1A-STATUS.md](PHASE-1A-STATUS.md) y [PHASE-1B-STATUS.md](PHASE-1B-STATUS.md) para su estado, preparación de Supabase Cloud y límites de seguridad.

Economía, avatares, tienda, misiones, clasificaciones, evaluación, laboratorio, comunidad y desafíos se conservan como funcionalidades experimentales hasta pasar pruebas integrales. Compras y recompensas económicas están deshabilitadas; el progreso local o histórico no produce monedas.

Para iniciar la aplicación web, sirva esta carpeta desde `localhost` y abra `index.html`. Ejecute las pruebas frontend existentes con `npm test`. La base Cloud se configura manualmente desde Supabase Dashboard, sin CLI ni Docker; siga las instrucciones y el orden de migración documentados en `PHASE-1B-STATUS.md`.
