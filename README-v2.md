# GestureChallenge — paquete de trabajo v2.0

Este paquete conserva la aplicación base y las funcionalidades de v2.0 agregadas previamente. Su estado y límites de alcance están documentados en [PHASE-1A-STATUS.md](PHASE-1A-STATUS.md).

La Fase 1a modulariza el frontend y el almacenamiento local. El reconocimiento de señas y el modo invitado se conservan. Los módulos de cuenta, economía, tienda, misiones, clasificaciones, evaluación, laboratorio, comunidad y desafíos permanecen marcados como experimentales, pendientes de validación.

Las compras y recompensas económicas están pausadas en la interfaz. Las migraciones de Supabase no se modificaron ni ejecutaron en esta entrega; sus correcciones y pruebas quedan para la siguiente autorización.

Para iniciar el modo web local, sirve esta carpeta desde `localhost` y abre `index.html`. Para las pruebas de progreso usa `npm test`.
